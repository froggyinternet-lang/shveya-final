Дата: 2026-11-04
Версия: v2.1
Статус: P0, не нарушать

## Ветка Планировщика (эта вкладка)

ID: PLANNER
Роль: координация, разбиение на задания, контроль прогресса
Что можно:
- Обсуждать план V5, обновлять TASK_LIST
- Обновлять MEMORY_INDEX, DECISIONS, LESSONS
- Создавать планы заданий TASK_XXX_plan.md
- Проверять готовность DONE файлов
- Решать что делать следующим

Что нельзя:
- Писать код
- Строить ER-модель, State Machine, DDL
- Выполнять задания 001-012
- Грузить больше 3 файлов за раз
- Держать в чате >3K токенов

Токен-бюджет: <3K

## Ветка Исполнителя (новые вкладки)

ID: EXECUTOR_XXX (XXX = номер задания)
Роль: выполнить одно маленькое задание
Что можно:
- Читать только: SHVEYA.md + MEMORY_INDEX.md + TASK_XXX_plan.md + один файл из 01_PLANS/
- Выполнять /plan → /build → /check → /memory
- Создавать TASK_XXX_done.md + обновлять KNOWLEDGE_GRAPH, CONTEXT
- Писать код в файлы /mnt/data/

Что нельзя:
- Обсуждать другие задания
- Грузить весь V5 (69KB) целиком
- Выполнять 2 задания в одной вкладке
- Возвращать дампы, только summary

Токен-бюджет: <6.5K
Жизненный цикл: открыл → выполнил → создал DONE → закрыл → вернулся в PLANNER

## Как переключаться

1. В PLANNER говоришь: "Начинаем 001"
2. Я создаю TASK_001_plan.md в мозг/03_TASKS/
3. Ты открываешь новую вкладку, загружаешь SHVEYA.md + TASK_001_plan.md
4. В новой вкладке пишешь промпт из NEW_TAB_001_PROMPT.txt
5. Выполняешь 001 там, создаешь DONE
6. Возвращаешься сюда и говоришь: "001 DONE, что дальше"
7. Я обновляю TASK_LIST и планирую 002

Нарушение = Context Rot, я слабею, проект путается.

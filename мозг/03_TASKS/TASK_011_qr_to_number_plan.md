## Проблема
Старое: у каждой вещи свой QR — где взять QR? Нужен принтер QR — у швеи в Мотовилихе нет.
Нужно: номер + наклейка рукой — швея пишет руками номер заказа, фамилию и адрес — чтобы Яндекс Такси не путались.

## Решение — Rule 7 обновлено: item_number + sticker_handwritten

### Что меняем в DDL

Старое:
- items.qr_code VARCHAR UNIQUE NOT NULL — только в items — QR принтер нужен
- orders без order_number

Новое:
- items.item_number VARCHAR(20) UNIQUE NOT NULL — человеческий номер — PRM-2026-0001 — вещь — UNIQUE — только в items
- items.qr_code VARCHAR NULL — опционально — если купим принтер, QR = item_number — может быть NULL — не обязательно
- orders.order_number VARCHAR(20) UNIQUE NOT NULL — номер заказа для наклейки — ORD-2026-0001 — человеческий
- transfer_history.item_number VARCHAR — проверка при выдаче — если не совпадает → ошибка перепутана 7
- CREATE UNIQUE INDEX items_item_number_unique ON items(item_number) — защита от дублей
- Старый qr_code индекс оставляем но делаем NULLABLE — для будущей совместимости

Генерация номера:
- Функция generate_item_number() — PRM-{YEAR}-{SEQ 4 цифры} — PRM-2026-0001 — SEQ из sequence
- Функция generate_order_number() — ORD-{YEAR}-{SEQ} — ORD-2026-0001 — для наклейки
- Просто — без QR — швея пишет рукой

### Наклейка — дизайн для швеи

Размер: 58x40 мм термо — дешёвые — 1000 шт 300 руб — выдаём швее рулон

Швея пишет рукой чёрным маркером:
```
┌─────────────────────────┐
│ Заказ №: 001            │
│ Фамилия: Иванов         │
│ Адрес: Пушкина 15-2     │
│ Вещь: Брюки черные      │
│ Кол-во: 1 вещь          │
│ Дата: 05.11.2026        │
└─────────────────────────┘
```

Зачем адрес рукой:
- Яндекс Такси / Доставка — водитель видит наклейку рукой — не путается с адресом в приложении — дубль
- Если 2 заказа в один дом — фамилия различает — Иванов vs Петров
- Швея пишет — фото наклейки обязательно Rule 4 — 5 фото — фото 1 Приём = фото наклейки + вещь

Пример для 2 вещей в одном заказе:
- Заказ ORD-2026-0001 — 2 вещи — PRM-2026-0001 и PRM-2026-0002
- Наклейка 1: "001-1 / Иванов / Пушкина 15-2 / Брюки"
- Наклейка 2: "001-2 / Иванов / Пушкина 15-2 / Пиджак"

### Что вшить в 3 SOP

SOP Швеи — обновить:
- Выдать рулон наклеек 58x40
- Писать рукой: номер заказа, фамилию, адрес, вещь, дату — чёрным маркером
- Клеить на пакет — 1 пакет = 1 вещь — 1 наклейка
- Фото наклейки + вещи — обязательно — 5 фото — фото 1 Приём
- Если QR принтер появится позже — QR = item_number — опционально — наклейка остаётся

SOP Курьера — обновить:
- При заборе — проверить номер на наклейке vs заказ в приложении — если не совпадает → ошибка перепутана 7 — нельзя забрать
- При доставке — показать клиенту наклейку — "Ваш заказ 001 Иванов" — клиент видит фамилию
- Яндекс Такси: в комментарии к заказу — "Заказ 001 Иванов Пушкина 15-2 — наклейка на пакете"

SOP Оператора — обновить:
- При создании заказа — генерить order_number и item_number — автоматом — PRM-2026-0001
- Писать на наклейке? Нет — швея пишет — оператор только генерирует номер в системе

### Миграция данных

- Если есть старые данные с qr_code — мигрировать: item_number = qr_code (если qr_code был человеческим) или сгенерить новый PRM
- qr_code делаем NULLABLE — старые данные остаются — новые без QR

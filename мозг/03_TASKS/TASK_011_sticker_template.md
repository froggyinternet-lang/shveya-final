# TASK_011_sticker_template.md — Шаблон наклейки 58x40 для швеи — Шаг 3
Дата: 2026-11-05
Размер: 58x40 мм — для термопринтера 58мм или ручного малярного скотча

## Что на наклейке

```
+---------------------------+
| PRM-2026-0001      16pt BOLD — item_number, читает швея
| ORD-2026-0001       8pt — order_number, пакет
| Куртка / Молния     10pt — тип из Garment
| Замена молнии 20см  9pt — дефект из Estimate
| [QR 15x15]          placeholder — QR = item_number когда купим принтер
+---------------------------+
```

## Как использовать без принтера (Concierge MVP 30 заказов)

1. Берешь малярный скотч 40мм
2. Пишешь маркером: PRM-2026-0001 крупно
3. Клеишь на вещь + фото наклейки + вещи в Photo 1 Приём (Rule 4)
4. Проверка при выдаче: сверяешь transfer_history.item_number = наклейке — ловит ошибку перепутана 7

## Как использовать с принтером (после гранта 10к)

1. Принтер 58мм — печатаешь шаблон с QR = item_number
2. QR ведет на карточку вещи

## Файлы для швеи

- Печатный: sticker_58x40.html — откроешь в браузере → печать
- Ручной: пишешь маркером

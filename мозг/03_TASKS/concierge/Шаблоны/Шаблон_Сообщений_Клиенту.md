# Шаблон Сообщений Клиенту — WhatsApp / Telegram

Скопируй в WhatsApp Business → Инструменты → Быстрые ответы.

## #1 Приняли заказ (NEW → ACCEPTED)
```
Здравствуйте, {Имя}! ✨
Приняли ваше изделие {Тип} — {PRM-2026-0001}
Дефект: {пятно на рукаве}
Срок: {3 дня до 16.05}
Предоплата: {500 сом}
QR накладной: {qr_url}
Отслеживание: напишите нам PRM-2026-0001 и мы скажем статус.
Спасибо! SHVEYA Concierge
```

## #2 В работе у швеи (IN_TRANSIT_TO_MASTER → WITH_MASTER)
```
{Имя}, ваше {PRM-2026-0001} уже у мастера Заремы 🧵
Мастер: специалист по {шелк/пятна}
Срок без изменений: {16.05}
Мы сообщим когда будет готово.
```

## #3 Готово к выдаче (READY)
```
Ура! 🎉 {Имя}, ваше {PRM-2026-0001} готово!
{Тип} — работа выполнена.
Баланс к оплате: {1000 сом}
Доставка: сегодня {16-19ч} или самовывоз {адрес}
Напишите удобное время.
```

## #4 Брак / Уточнение (DEFECT)
```
{Имя}, по {PRM-2026-0001} нужна ваша консультация ⚠️
{Описание брака: пятно не вывелось полностью, остался след 1мм}
Фото: {photo_url}
Варианты:
1. Оставляем как есть, скидка 20%
2. Пробуем еще раз (риск ткани) +1 день
3. Возврат предоплаты
Что выбираете?
```

## #5 Доставлено (DELIVERED)
```
{Имя}, спасибо что выбрали нас! 🙏
{PRM-2026-0001} доставлен.
Будем благодарны за отзыв: {ссылка на 2GIS/Google}
Промокод на следующий заказ: SPASIBO10 -10%
До встречи!
```

## #6 Просрочка (если is_overdue)
```
{Имя}, извините за задержку по {PRM-2026-0001} 😔
Причина: {задержка у мастера}
Новый срок: {завтра до 12:00}
Компенсация: доставка бесплатно / скидка 15%
```

## #7 Напоминание про оплату
```
{Имя}, напоминаем про баланс по {PRM-2026-0001}: {1000 сом}
Оплатить можно:
- Наличными курьеру
- Переводом {МБанк}
- По QR в накладной
```

## Переменные для подстановки из Google Sheets:
- {Имя} = Clients.name
- {PRM} = Orders.item_number
- {Тип} = Garments.type
- {qr_url} = Orders.qr_url
- {photo_url} = Garments.photo_url

## Как отправлять без кода:
- Вручную копируешь шаблон → подставляешь из Sheets → отправляешь
- Или через n8n: Telegram node → Send Message to Client (если у клиента есть telegram)

## Сохрани как быстрые ответы WhatsApp:
- /принято → шаблон #1
- /в_работе → #2
- /готово → #3
- /брак → #4
- /доставлено → #5

# QR Без Кода — PRM-2026-0001 + печать 30x20мм

## Принцип без сервера и без кода
Используем бесплатный Google Chart API для генерации QR. Никаких библиотек, никакого сервера.

## Формула QR

### Базовый URL:
```
https://chart.googleapis.com/chart?chs=150x150&cht=qr&chl=PRM-2026-0001
```
Где:
- `chs=150x150` — размер картинки 150x150 пикселей (для 30x20мм достаточно, для печати лучше 300x300)
- `cht=qr` — тип chart = QR code
- `chl=PRM-2026-0001` — данные внутри QR (наш item_number)

### Варианты:
- Маленький для таблицы: `chs=100x100`
- Средний для наклейки: `chs=150x150`
- Большой для печати: `chs=300x300` или `chs=500x500`
- С коррекцией ошибок (чтобы читался даже мятый): `&chld=H|1` → `https://chart.googleapis.com/chart?chs=300x300&cht=qr&chl=PRM-2026-0001&chld=H|1`

## Как сгенерировать QR в Google Sheets без кода (3 способа)

### Способ 1 — Формула IMAGE (рекомендуется)
В ячейке Orders!M2:
```
=IMAGE("https://chart.googleapis.com/chart?chs=150x150&cht=qr&chl="&B2)
```
Где B2 = PRM-2026-0001. Картинка появится прямо в ячейке.

### Способ 2 — Формула HYPERLINK с QR URL
В L2:
```
="https://chart.googleapis.com/chart?chs=300x300&cht=qr&chl="&B2
```
Потом =IMAGE(L2)

### Способ 3 — Массовая генерация
Выдели столбец L → протяни формулу вниз → все заказы получат QR автоматически.

## Что внутри QR?
Только item_number: `PRM-2026-0001`

При сканировании телефоном:
- Курьер/швея сканирует → попадает в Telegram бот с предзаполненным `PRM-2026-0001` (можно настроить deep link)
- Или сканирует → открывает Google Sheet фильтр: `https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID#gid=0&range=B:B` + поиск

### Продвинутый QR с данными (опционально):
Если хочешь закодировать больше:
```
https://chart.googleapis.com/chart?chs=300x300&cht=qr&chl=PRM-2026-0001|Клиент:Алия|Платье|1500сом
```
Но MVP — только PRM.

## Печать 30x20мм без кода и без сервера

### Требования из TASK_007:
- Размер наклейки: 30мм ширина x 20мм высота (термоэтикетка)
- Содержит: QR + PRM-2026-0001 + Тип + Клиент (сокращенно)

### Вариант A — Термопринтер (Xprinter 365B, 2000₽) — лучший
1. Купи ленту 30x20 термо (500шт ~300₽ на WB)
2. Открой `Шаблоны/Наклейка_30x20_шаблон.html` в Chrome
3. Вставь PRM-2026-0001 → нажми Печать → выбери принтер → размер 30x20 → Печать
4. Готово. Шаблон уже сверстан под 30x20.

### Вариант B — Обычный лазерный принтер + самоклейка A4 (самый дешевый, <6.5K)
1. Купи самоклейку А4 65 наклеек на листе (30x20мм) ~200₽ за 100 листов
2. Открой Google Sheets → лист `Печать_Наклеек` (создай)
   - A1: item_number, B1: qr_url
   - Заполни 65 строк
3. Используй слияние: `Шаблоны/Наклейка_30x20_шаблон.html` имеет сетку 5x13 (65 наклеек)
4. Печать на лазерном → вырезать не надо, отклеиваются.

### Вариант C — Ручной (совсем без принтера на старте)
1. Открой QR ссылку: https://chart.googleapis.com/chart?chs=300x300&cht=qr&chl=PRM-2026-0001
2. Сохрани картинку
3. Вставь в Word → добавь текст PRM-2026-0001 → распечатай на обычной бумаге → скотчем на пакет.
MVP допускает.

# Чеклист Оператора — Concierge без приложения

**Роль:** Прием заказа у клиента (WhatsApp / звонок / офлайн). Работает только в Google Sheet + Telegram.

### Прием нового заказа (NEW)

- [ ] 1. Создать строку в листе Orders: нажать Enter в конце таблицы
- [ ] 2. item_number сгенерируется авто: `=PRM-YYYY-NNNN` (PRM-2026-0001) — проверить
- [ ] 3. Заполнить client_id: найти в Clients или создать нового (VLOOKUP)
- [ ] 4. Заполнить garment: тип, ткань, цвет, дефект (из Garments)
- [ ] 5. Сфоткать изделие (3 фото: общий, дефект, бирка) → загрузить в Google Drive → ссылку в Garments.photo_url
- [ ] 6. Сгенерировать QR: формула уже есть в qr_url → скопировать ссылку → открыть → проверить что читается PRM-2026-0001
- [ ] 7. Распечатать наклейку 30x20мм из Шаблоны/Наклейка_30x20_шаблон.html
- [ ] 8. Наклеить QR на пакет + на накладную (дубль)
- [ ] 9. Заполнить Payments: prepayment если взяли
- [ ] 10. Сменить статус на ACCEPTED (или нажать кнопку Приняла в боте)
- [ ] 11. Отправить клиенту сообщение #1 из Шаблоны/Шаблон_Сообщений_Клиенту.md: "Приняли PRM-2026-0001"
- [ ] 12. Создать Transfer: from=OPERATOR to=MASTER, courier_id выбрать
- [ ] 13. Логировать в Events: message_id если через бота, иначе ручной

### Что нельзя делать:
- Не менять item_number вручную
- Не дублировать PRM
- Не клеить чужой QR

### Если брак:
- [ ] Сфоткать брак → в Garments.defect_desc
- [ ] Статус DEFECT → написать клиенту шаблон #4

### Конец дня:
- [ ] Проверить Dashboard: сколько NEW осталось
- [ ] Проверить is_overdue

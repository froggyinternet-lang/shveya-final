# QR Формат PRM-2026-0001 — SHVEYA.md v2.4 Rule 7

## Формат item_number
- Шаблон: PRM-YYYY-NNNN
- Regex: ^PRM-\d{4}-\d{4}$
- Пример: PRM-2026-0001
- UNIQUE в items.item_number (001_initial_final.sql)
- Генерация: sequence item_seq 1..9999 в год, сброс 1 января. Код:
```python
def gen_item_number(year):
    seq = db.nextval('item_seq')  # 1..9999
    return f"PRM-{year}-{seq:04d}"
```

## Payload QR
Вариант A (простой, рекомендуется): plain text
```
PRM-2026-0001
```

Вариант B (URL, для сканера с браузером):
```
https://perm.local/i/PRM-2026-0001
или https://perm-repair.local/item/PRM-2026-0001
```

Рекомендация: печатать plain PRM-2026-0001 — сканеры читают быстрее, не зависит от сети.

## Технические параметры QR
- Version: 2 (25x25) достаточно для 11 символов
- ECC: M (15%) или Q (25%) — для потертостей
- Size: 15x15 мм минимум QR поле, общий стикер 30x20 мм
- Quiet zone: 4 модуля
- Encoding: UTF-8, Alphanumeric

## DDL связь
```sql
items.item_number TEXT UNIQUE CHECK (item_number ~ '^PRM-\d{4}-\d{4}$')
artifacts.item_id → items.id
transfer_history.item_id → items.id
return_confirmations.item_id → items.id
events.idempotency_key UNIQUE
```

## Жизненный цикл QR
1. Генерация при приемке
2. Печать 1 наклейка + 1 дубликат в пакет
3. Скан: приемка, швея 3 кнопки, курьер 2 плеча, выдача
4. Архив после ВЫДАНО — не переиспользовать номер

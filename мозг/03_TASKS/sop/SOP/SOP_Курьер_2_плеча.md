# SOP_Курьер_2_плеча — pickup / return + 14 исключений

**Версия:** v1.0 TASK_006 | 2 плеча + CHECK IN

### Модель 2 плеча
- Плечо 1: PICKUP — забор у клиента → пункт приемки
- Плечо 2: RETURN — выдача из пункта → клиент
Каждое плечо = отдельный CHECK IN в системе.

### CHECK IN обязателен
- Гео + фото + скан QR PRM-2026-0001
```sql
INSERT INTO transfer_history (item_id, from_stage, to_stage, actor, meta)
VALUES (<id>, 'В_ПУТИ_PICKUP', 'ПРИЕМКА', 'courier_petya', '{"check_in": true, "lat":..., "lon":..., "photo_url":"..."}');
```

### Процесс PICKUP
1. Прибыл → CHECK IN (кнопка в приложении)
2. Сверил вещь с фото из заявки (если есть)
3. Наклеил временный QR если нет постоянного (PRM-2026-0001)
4. Фото 1 шт при заборе → artifacts type='courier_pickup'
5. CHECK OUT

### Процесс RETURN
1. Прибыл → CHECK IN
2. Скан QR PRM-2026-0001 → 7 проверок из SOP_Выдача
3. Фото return_confirmations (Rule 4) — обязательно
4. customer_confirmed
5. CHECK OUT

### 14 исключений — 6 колонок

| № | Код | Ситуация | Действие курьера | Кому сообщить | Фото/QR |
|---|---|---|---|---|---|
|1|NO_CLIENT|Клиент не дома|Ждать 10 мин, 2 звонка|Диспетчер в чат|Фото двери|
|2|BAD_ADDR|Адрес неверный / нет квартиры|Уточнить у клиента, гео-точка|Диспетчер|Скрин карты|
|3|NOT_READY|Вещь не готова к выдаче (статус не ГОТОВО)|Не забирать, перенести|Приемка|Скан QR|
|4|DIRTY_ITEM|Вещь грязная/в пятнах при pickup|Фото, спросить клиента везти ли|Приемка|Фото дефекта|
|5|SIZE_MISMATCH|Не тот размер/вещь|Не забирать|Приемка + Диспетчер|Фото бирки + QR|
|6|REFUSE|Клиент отказывается отдавать/принимать|Фикс причину, без конфликта|Диспетчер|Фото + аудио заметка|
|7|NO_PAY|Нет оплаты при выдаче|Не выдавать без оплаты, кроме предоплаты|Касса|Фото QR|
|8|QR_DAMAGED|QR поврежден/не читается|Ввести PRM-2026-0001 руками + фото|Приемка|Фото QR|
|9|NO_ANSWER|Телефон не отвечает|3 попытки с интервалом 5 мин|Диспетчер|Скрин звонков|
|10|INTERCOM|Домофон не работает / нет кода|Ждать у подъезда, просить выйти|Клиент|Фото подъезда|
|11|WEATHER|Погодные условия опасны|Перенос по согласованию|Диспетчер|Фото условий|
|12|DAMAGED_TRANSIT|Вещь повреждена при перевозке|Стоп, фото, изолировать|Старший + Приемка|Фото повреждения + QR|
|13|SWAP|Перепутали заказы (2 пакета)|Сверить оба QR, не выдавать чужое|Приемка СРОЧНО|Фото обоих QR|
|14|NEIGHBOR|Клиент просит оставить у соседа/консьержа|Только с подтверждением в чате + ФИО соседа + фото|Диспетчер + лог в events|Фото передачи + QR|

### Правила фото
- Каждое исключение — минимум 1 фото в artifacts или return_confirmations
- QR должен быть в кадре если вещь в руках курьера

### Запреты
- Оставлять без фото — ЗАПРЕТ
- Отдавать без CHECK IN — ЗАПРЕТ
- Менять item_number — ЗАПРЕТ, только сканировать PRM-2026-0001

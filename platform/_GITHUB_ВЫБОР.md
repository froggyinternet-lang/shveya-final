# Основа ШВЕЯМОЗГ

**Выбрана одна основа:** [официальный Full Stack FastAPI Template](https://github.com/fastapi/full-stack-fastapi-template), MIT, снимок ветки `master` от 7 ноября 2026 года. Внутри архива сохранены его лицензия и уведомления об авторских правах.

На Этапе 0 первоначально рассматривался [erp-lite](https://github.com/makkyxa/erp-lite). После уточнения полного клиентского потока и проверки исходников решение изменено: его `GET /orders` не фильтрует доступ по назначенному мастеру, `Photo` привязана к заказу, используется автомобильная модель и демонстрационный пароль. Переписывать ядро такого проекта рискованнее, чем расширить проверенный каркас с готовой авторизацией и тестами. [SmartBooking](https://github.com/Ophion666/SmartBooking-Appointment-and-Payments) содержит Telegram и платежный пример, но без панели и с отдельным Celery/Redis; его код не копируется.

К одному каркасу добавлены независимые адаптеры официальных API. Для Telegram ориентир — [aiogram](https://github.com/aiogram/aiogram) (MIT), для VK — [официальная схема](https://github.com/VKCOM/vk-api-schema), для MAX — [официальная документация](https://dev.max.ru/docs-api), для логистики — [Яндекс Доставка B2B](https://yandex.ru/support/delivery-profile/ru/api/express/quickstart). Схемы и SDK третьих лиц не копируются. Единственный источник данных — PostgreSQL.

Сравнение кандидатов и исходные метрики остаются в отдельном файле Этапа 0. Приоритет в новом решении: fail-closed доступ к данным клиента, возможность подключения нескольких каналов и небольшая нагрузка на сервер 4 ГБ.

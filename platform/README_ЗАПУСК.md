# ШВЕЯМОЗГ — запуск в Перми

Это новая платформа в подпапке `Perm_Repair/platform`; исходные материалы Meta AI остаются рядом и не перезаписываются. Основа кода — MIT-шаблон FastAPI + React, лицензия в `LICENSE`.

## Первый запуск

1. Установите Docker Desktop с Compose. В терминале откройте папку `platform`.
2. Скопируйте `.env.example` в `.env` и заполните только имеющиеся ключи. Для первых заказов оставьте `DELIVERY_PROVIDER=partner`. Никогда не публикуйте `.env`.
3. Выполните `docker compose up --build -d`.
4. Откройте `http://localhost:8080`. Первый аккаунт владельца: `OWNER_EMAIL` из `.env` (по умолчанию `owner@localhost.local`). Пароль генерируется при первом запуске; посмотреть его можно командой `docker compose exec app cat /run/secrets/owner_password`. Сразу задайте собственный пароль через профиль.
5. Добавьте швей с точными адресами, координатами, навыками и зонами. Для доставки компаньоном создайте тариф каждой зоны в настройках/API `/api/admin/tariffs` (суммы обоих плеч). Затем проверьте тестовый заказ, цену швеи, наценку, доставку и один платёж.

## Внешние сервисы

Telegram, VK и MAX требуют отдельных токенов, настройки webhook, публичного HTTPS-домена и проверки их событий. Яндекс Доставка требует B2B-договора, токена, реальных телефонов/почт контактов и объявленной стоимости вещи; Яндекс Геокодер — ключа Maps API. YooKassa требует магазина и секретного ключа; для одного платежа укажите `YOOKASSA_VAT_CODE` и `YOOKASSA_RETURN_URL`, а фискальные чеки и способ расчёта проверьте в личном кабинете и договоре. Значения переменных приведены в `.env.example`. Без ключей эти сервисы не заработают, а режим `partner` доступен для ручной логистики.

В мессенджере бот не получает IP клиента для определения адреса. Просите адрес или геолокацию явно. Обратная доставка оценивается при выставлении единого счёта; если фактический тариф позже изменится, клиентская сумма остаётся зафиксированной, отклонение учитывается за счёт платформы. Доставка выполняется только после подтверждения оплаты. Запрос времени ограничен доступностью тарифа Яндекса.

## Проверка перед реальными заказами

Пройдите полный сценарий на тестовых аккаунтах: фото и голос клиента → адрес → назначение швеи → оценка → две цены доставки → один платёж → вывоз → фото «готово» → подтверждение возврата → вручение. Отдельно проверьте возврат платежа, спор, отсутствие курьера и изменение тарифа. Для эксплуатации нужен резервный копий PostgreSQL и фотографий, мониторинг ошибок и публичный HTTPS с ограниченным доступом к админке.

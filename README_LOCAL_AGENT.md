# ШВЕЯМОЗГ — Как дать Meta AI доступ как Claude Code

## Проблема
Meta AI в облаке, не видит твой C:\. Это защита, не галочка. Claude Code может потому что УСТАНОВЛЕН у тебя локально.

## Решение — 2 команды

### Вариант 1: Простой (рекомендую) — local_agent.py

1. Скачай local_agent.py в C:\Perm_Repair\
2. Открой cmd: Win+R -> cmd -> cd C:\Perm_Repair
3. Запусти: python local_agent.py
4. Нажми 2 -> он создаст Perm_Repair_for_MetaAI.zip
5. Перетащи zip в этот чат — я сам прочитаю все файлы P1-P5, панель, ботов
6. Я верну patch.json — сохрани его в C:\Perm_Repair\patch.json
7. В агенте нажми 3 -> он применит мои исправления с бэкапом

Ты получаешь кнопку "дай доступ" как в Claude Code, но с контролем: ты видишь что я меняю.

### Вариант 2: Продвинутый — local_agent_pro.py (FastAPI)

1. pip install fastapi uvicorn
2. python local_agent_pro.py
3. Открой http://localhost:8000/list
4. Скажи мне в чате "локальный агент на localhost:8000" — я скажу какие файлы прочитать, ты копируешь ответы

## Что я смогу после этого

- Сам читать твои бывшие проекты с видеогенератором которые у тебя на компе (P1-P5)
- Сам править панель, ботов, деплоить на сервер Яндекс Клауд который возьмем на Никиту
- Сам собирать V5 и применять патчи без твоего ручного копирования

## Безопасность

- Агент работает ТОЛЬКО внутри C:\Perm_Repair, наружу не выходит
- Перед перезаписью делает бэкап в .backup/
- Спрашивает подтверждение y/N
- Ничего не отправляет в интернет сам

## Если Python не установлен

Скачай с python.org, при установке поставь галочку "Add Python to PATH"

## Для Яндекс Cloud

В агенте кнопка 5 проверяет yc CLI. Установи с cloud.yandex.ru/docs/cli/quickstart
Потом: yc init, выбери облако Никиты
